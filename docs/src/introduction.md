# Introduction

<p align="center">
  <img src="images/drakeflake-logo.svg" alt="The DrakeFlake logo" width="160">
</p>

<p align="center"><em>NixOS, tamed.</em></p>

DrakeFlake is a desktop app for NixOS and nix-darwin systems that are configured
with a flake. With it you can:

- search all NixOS options (or nix-darwin options on a Mac) of your system, see
  their current value and change them,
- change the Home Manager settings of the users on your host (when Home Manager
  is used as a NixOS or nix-darwin module),
- search packages from the nixpkgs your system uses, add them to the system or
  try them without installing,
- look up Nix functions of `lib`, `builtins` and `pkgs` with their
  documentation,
- see the inputs in your `flake.lock`, check them for updates and update them,
- rebuild the system, go back to an earlier generation and free disk space.

![The Overview, where the app starts](images/overview.png)

## Try it now

You need:

- NixOS on x86_64 or aarch64, or macOS on Apple silicon with nix-darwin,
- a flake-based system configuration.

To run DrakeFlake straight from the repository without installing anything:

```sh
nix run github:dr460nf1r3/drakeflake/stable
```

`stable` is the newest version that passed all automatic tests. It moves
forward after every change that passes them. Without `/stable`, you get the
newest state of the code, tested or not.

On first start the [setup assistant](setup.md) helps you pick your flake and
host. To keep the app, [install it](installation.md). If the app does not start
or the window stays empty, see [Troubleshooting](troubleshooting.md).

## What it changes

Everything you change is written to **generated files** inside your system
flake:

- by default `drakeflake.nix` next to your `flake.nix`,
- with a split layout, also the files in a `drakeflake/` folder next to it.

Your host configuration imports the generated file once. The setup assistant
shows the line to add and checks that it is in place.

Every generated file starts with this header:

```nix
# GENERATED by DrakeFlake - safe to delete.
# Hand edits inside this file are overwritten on next Apply.
```

The app only overwrites or removes `.nix` files that carry this header (or are
empty), and only inside a flake. A file without the header is never replaced.

The generated settings are ordinary NixOS module code. You can:

- read them at any time (**Changes → Preview file**),
- commit them to git with the rest of your flake,
- delete them to undo everything the app did.

## How changes flow

1. You change an option or add a package. The change is **staged**: it is kept
   in a list, and nothing is written yet.
2. Staged values are checked against the option's type in the background.
3. On the **Changes** page you look at the list, preview the generated file and
   choose how to apply:
   - switch now (**Apply**),
   - on the next boot (**Apply on next boot**),
   - until the next reboot (**Apply until reboot (test)**),
   - only save (**Save only**) or build (**Save and test build**).

   Which of these the page offers depends on the host, for example on a host of
   another kind than this machine.

4. The app writes the generated files (keeping a backup of the previous ones)
   and rebuilds the system. The output appears in the **Console**.

Staged changes survive a restart of the app. They are kept separately for each
flake and host.

> **Note:** Applying asks for your password and changes your running system. To
> go back, boot or switch to an earlier generation, or restore an earlier apply
> from **History**. See [Reviewing and applying](applying.md) and
> [Generations, cleanup and actions](maintenance.md).

## The window

The sidebar on the left lists the sections in four groups, browsing,
managing, reviewing and the application itself, with dividers between them:

| Section           | What it is for                                                        |
| ----------------- | --------------------------------------------------------------------- |
| **Overview**      | Your system at a glance and one search over everything                |
| **Options**       | Search and change NixOS options                                       |
| **Home Manager**  | Settings of the users on this host                                    |
| **Packages**      | Add, remove or try packages                                           |
| **Functions**     | Nix functions of lib, builtins and pkgs, with documentation           |
| **Generations**   | Go back to an earlier system (only for a host of this machine's kind) |
| **Tree View**     | Every option, including defaults, as an expandable tree               |
| **Configured**    | Everything set in your flake                                          |
| **Actions**       | Rebuild, create images, start in a VM                                 |
| **Cleanup**       | Free disk space                                                       |
| **Inputs**        | Check and update `flake.lock`                                         |
| **Impermanence**  | What survives a reboot and what is removed                            |
| **History**       | Earlier applies and their files                                       |
| **Changes**       | Review and apply staged changes                                       |
| **Console**       | Output of the programs the app runs                                   |
| **Settings**      | Flake, host, layout, tray and logging                                 |
| **Documentation** | This handbook, inside the app                                         |
| **About**         | Version, a short description and links                                |

While changes are staged, the sidebar entry shows their number, for example
**Changes (3)**. While a program runs, it shows **Console (running)**.

On narrow windows the sidebar collapses to icons. **About** links to this
documentation at
[dr460nf1r3.github.io/drakeflake](https://dr460nf1r3.github.io/drakeflake/), the
source code and the issue tracker.

The app opens on the **Overview**. It shows which system you manage, one search
over everything (options, packages, Home Manager, inputs, generations, settings
and actions) and tiles for the main sections. See
[Overview and search](overview.md).

Details of an option or a package open in a second column next to the list. On
a narrow window the details column does not fit next to the list. The details
then replace the list, and a back button in the toolbar takes you back to it.

The title names the host you manage, for example `testhost — DrakeFlake`.
The app remembers the size and position of its window and restores them on
the next start. **Toggle Full Screen** in the **Window** menu fills the
screen. On a Mac the window joins the system tabs and shows a dot in the
title bar while changes are staged. The Mac Accessibility settings are
honoured too: **Reduce Transparency** keeps the window solid instead of
blurred and **Reduce Motion** stills the status bar. On Linux the window
follows the desktop theme.

While the app evaluates your configuration or runs a command, a status bar at
the bottom of the window shows what it is doing. While changes are applied it
says **Applying changes…**. Click **Show console** in the status bar to follow
the output. The button is hidden while the **Console** is already open.

### Read the documentation in the app

**Documentation** in the sidebar opens this handbook inside the app. The
contents are on the left, grouped like the online version. Type into
**Search the documentation…** above the contents to find a page by its
title or group. Click a page to
open it in a column next to the contents. Links to other pages and headings
stay in the app. Links to websites open in your browser. **Open Online** in the
toolbar opens the handbook at
[dr460nf1r3.github.io/drakeflake](https://dr460nf1r3.github.io/drakeflake/).

To read about the page you are on, click **Help** in its toolbar or press
<kbd>F1</kbd> (**Help for This Page** in the **Help** menu). The handbook then
opens at the part that describes that page, for example the
[tree](options.md#browse-all-options-as-a-tree) for the **Tree View**.

The pages come with the app. They always match the version you run and need no
network connection.

### See the full text of a row

Lists shorten long text to fit. Hold the pointer over a row to see the full
text in a tooltip:

| Where                                      | The tooltip shows                                   |
| ------------------------------------------ | --------------------------------------------------- |
| **Options**, **Packages**, **Functions**   | The full description, when it is cut off in the row |
| **Home Manager**, **Configured**           | The description and the full value                  |
| **Tree View**                              | The description of the option                       |
| Tags (small labels on rows and in details) | The full tag text, when it is shortened             |

## Keyboard

The menu bar holds every section under **View**, text commands under
**Edit**, and **DrakeFlake Handbook** (the
[built-in documentation](#read-the-documentation-in-the-app)) and **About
DrakeFlake** under **Help**. On a Mac it is the native menu at the top of the
screen. On a Linux desktop with a global menu (for example KDE Plasma with the
Global Menu widget in a panel) the same menus appear there and the window has
no menu bar of its own. DrakeFlake checks for the global menu when it starts,
so restart it after adding the widget. Shortcuts use <kbd>Ctrl</kbd> on Linux
and <kbd>⌘</kbd> on a Mac:

| Shortcut                                                                     | What it does                                                                                                                           |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| <kbd>Ctrl+1</kbd> to <kbd>Ctrl+9</kbd>                                       | Open **Overview**, **Options**, **Home Manager**, **Packages**, **Functions**, **Generations**, **Actions**, **Cleanup** or **Inputs** |
| <kbd>Ctrl+F</kbd>                                                            | **Find in Page**: focus the search field of the open page                                                                              |
| <kbd>Ctrl+[</kbd>                                                            | **Back** out of the open details (popped pages are gone, so nothing goes forward)                                                      |
| <kbd>Esc</kbd>                                                               | **Back** out of the open details                                                                                                       |
| <kbd>Ctrl+S</kbd>                                                            | **Save Changes**: write the file without rebuilding                                                                                    |
| <kbd>Ctrl+M</kbd>                                                            | Minimize the window                                                                                                                    |
| <kbd>Ctrl</kbd>+<kbd>⌘</kbd>+<kbd>F</kbd> on a Mac, <kbd>F11</kbd> elsewhere | **Toggle Full Screen**                                                                                                                 |
| <kbd>Ctrl+Q</kbd>                                                            | Quit DrakeFlake                                                                                                                        |
| <kbd>Ctrl+,</kbd>                                                            | Open **Settings…**                                                                                                                     |
| <kbd>F1</kbd> (<kbd>⌘+?</kbd> on a Mac)                                      | **Help for This Page**: the part of this handbook about the open page                                                                  |

**Copy**, **Cut**, **Paste**, **Undo**, **Redo** and **Select All** under
**Edit** work in every text field and follow the field: they are greyed out
where the field cannot do them. Right-clicking a field opens the same
commands where the pointer is.

- The search field has the focus when you open **Overview**, **Options**,
  **Home Manager**, **Packages**, **Functions** or **Configured**. You can start
  typing right away.
- Filter pickers (for example on **Packages**, **Functions** or **Actions**)
  open a list with a search field. Type to narrow the list, then press
  <kbd>Enter</kbd> to pick the first match.
- On **Settings**, <kbd>Enter</kbd> in the **System flake:** or
  **Output file:** field does the same as **Use this system**.
- When a program in the **Console** asks for a password, type it and press
  <kbd>Enter</kbd> to send it, like **Send**.
- On the **Overview**, the arrow keys, <kbd>Enter</kbd> and <kbd>Esc</kbd> move
  through the search hits. See [Open a hit](overview.md#open-a-hit).
